# Local robotics data

Downloaded datasets live under `data/external/` and are intentionally ignored by Git.

Current dataset:

- `so100_dataset50ep/` — [RasmusP/so100_dataset50ep](https://huggingface.co/datasets/RasmusP/so100_dataset50ep)
- LeRobot format, 50 episodes, joint/action parquet files, and laptop/phone video streams
- Downloaded 2026-08-03 for local research; review the upstream dataset card before redistribution

- `svla_so100_pickplace/` — [lerobot/svla_so100_pickplace](https://huggingface.co/datasets/lerobot/svla_so100_pickplace)
- LeRobot format, 50 episodes, 19,631 frames, 6-joint actions, and synchronized `top` plus `wrist` video streams
- Downloaded 2026-08-03 for local research; review the upstream dataset card before redistribution
