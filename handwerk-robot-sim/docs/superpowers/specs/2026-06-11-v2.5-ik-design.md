# v2.5 — H1 Cartesian IK via mink

**Date:** 2026-06-11  
**Status:** approved

## Goal

Replace the scripted right-arm animation in the H1 replay loop with real inverse kinematics. The arm traces a boustrophedon (zigzag) grid across a virtual wall plane; EEG fatigue modulates traversal speed. Everything else — WS protocol, Angular, torso scripting, leg poses — unchanged.

## Scope

Three files change:

| File | Change |
|---|---|
| `requirements.txt` | Add `mink>=1.1`, `qpsolvers[clarabel]>=4.3` |
| `sim/ik.py` | Add `H1IkSolver` class; keep `wall_zigzag()` as-is |
| `sim/ws_server.py` | Init solver + waypoints on `replay`; IK loop replaces `qpos` assignment |

`sim/trowel_h1.py` is untouched. Torso yaw (joint 10) is still read from `troweling_targets()` and overlaid after each IK step.

## Architecture

### `H1IkSolver` (sim/ik.py)

mink differential IK targeting `right_elbow_link` body frame (no XML site needed).

```python
class H1IkSolver:
    ARM_JOINTS = slice(15, 19)  # right_shoulder_pitch/roll/yaw + right_elbow

    def __init__(self, model, data):
        self.cfg = mink.Configuration(model, data)
        self.task = mink.FrameTask(
            frame_name="right_elbow_link",
            frame_type="body",
            position_cost=1.0,
            orientation_cost=0.0,
        )
        self.limits = [mink.ConfigurationLimit(model)]

    def set_target(self, pos: np.ndarray) -> None:
        self.task.set_target(mink.SE3.from_translation(pos))

    def step(self, dt: float) -> None:
        vel = mink.solve_ik(self.cfg, [self.task], dt,
                             solver="clarabel", limits=self.limits)
        self.cfg.integrate_inplace(vel, dt)
```

### Wall grid

Fixed boustrophedon grid defined in `sim/ik.py`:

```python
WALL_WAYPOINTS = list(wall_zigzag(
    origin=(0.65, -0.25, 1.4),
    width=0.5,
    height=0.5,
    rows=4,
    step=0.15,
))
```

~4 horizontal passes at torso height, 0.65 m in front of H1. Numbers tunable.

### `ws_server.py` replay loop

New state fields set on `{cmd:replay}`:

```python
state['waypoints']   = WALL_WAYPOINTS
state['wp_progress'] = 0.0          # float, advances each frame
state['ik_solver']   = H1IkSolver(model, data)
```

Per-frame (replaying, H1 model):

```python
SECS_PER_WP = 1.5

speed = 1.0 - fatigue * (1.0 - MIN_SPEED)
state['wp_progress'] += dt * speed / SECS_PER_WP
wp_idx = min(int(state['wp_progress']), len(waypoints) - 1)

solver.set_target(waypoints[wp_idx])
solver.step(dt)

torso_yaw = h1_targets(t, fatigue=fatigue, in_flow=in_flow)[10]
data.qpos[7 + 10] = torso_yaw

mujoco.mj_forward(model, data)
```

Waypoint exhaustion (`wp_progress >= len(waypoints)`) transitions `status → 'idle'`, same as existing EEG-tick exhaustion.

## Error handling

- mink QP infeasible (target unreachable): catch exception, hold current qpos, print warning — no sim crash
- `H1IkSolver` created fresh on each `replay` command — no stale state
- Joint limits enforced by `mink.ConfigurationLimit` — no manual clamping

## Testing

Manual only (no automated test suite):

1. `mjpython sim/ws_server.py --model h1` → Angular → Transfer → arm traces boustrophedon grid
2. Stdout `[ik] wp N/M err=X.XXXm` per waypoint — confirm convergence
3. Vary mock fatigue → arm slows visibly
4. Session ends → H1 returns to idle standing keyframe
